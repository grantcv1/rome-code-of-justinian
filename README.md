# The Code of Justinian in Akoma Ntoso

The whole Code of Justinian (534) in Akoma Ntoso XML, in S. P. Scott's English translation of 1932, with a stylesheet and a page that show it in the manner of a sixth-century manuscript. It was generated by Claude for Grant Vergottini.

It has three prefaces, 12 books, 763 titles and 4,545 numbered provisions, at about 585,000 words.

## Files

| File | Purpose |
| --- | --- |
| `code-of-justinian.xml` | The Akoma Ntoso document |
| `code-of-justinian.css` | The stylesheet, linked from the XML |
| `view.html` | The manuscript page, one opening at a time, with Book and Title menus |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the rendition

No original copy of the Code survives. This is a rendition in period style, not a facsimile of any manuscript, and it is in English, which no such manuscript was.

It draws on features of late antique legal books: uncial letters, red rubrics for titles, inscriptions and dates, two columns, Roman numerals and almost no space between words. The Uncial Antiqua font is a modern design, not a copy of a sixth-century hand.

All of this comes from the stylesheet and `view.html`. The page changes two things for display only: it shows numbers as Roman numerals, and it shows a dash for the damaged characters listed below. The XML keeps the source as it is.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Structure:** An `<act name="code">` holds the prefaces as `<hcontainer name="prefatoryConstitution">`, then `<book>`, `<title>`, `<article>` and `<paragraph>` elements.
- **Constitutions:** Each numbered constitution is an `<article>`. Its inscription, such as "The Emperor Constantine to the People.", is the `<heading>`.
- **Subscriptions:** The closing date line is a `<p class="subscription">`, in `<wrapUp>` where the constitution has numbered paragraphs and at the end of `<content>` where it does not.
- **`intro` and `content`:** Text followed by numbered paragraphs is in `<intro>`. Other text is in `<content>`.
- **Identifiers:** Every element with an `eId` also has a `GUID`. Text-level `<p>` elements have neither. There are 5,977 of each, all unique.
- **Cross-references:** These are left as plain text. They were not linked.

The metadata uses the jurisdiction code `rome` and the date of November 16, 534, the date usually given for the second edition. Scott's text says "the seventeenth day of the Kalends of December", which would be a day earlier.

## Left as they are

An in-order check of all 584,514 words against the source files shows no differences. The only things left out are the file headers: the repeated "The Enactments of Justinian. The Code." lines, the "~ Book ~" decoration and the citation line. The letter-spaced headings of the prefaces were closed up. "Book I" and so on are set as numbers.

These oddities were kept:

| Where | As in the source | Note |
| --- | --- | --- |
| Books V to VII, XII | 23 damaged characters (U+FFFD) | Probably dashes lost in conversion. Shown as dashes on the page |
| Book I | "Titles 42-43. The Latin texts of these two titles are missing." | Kept as a note |
| Book II, Title 28 | "New Constitution of Frederick." | A medieval addition, inserted between constitutions 1 and 2 |
| Books VII to XII | "This Law is not Authentic." and similar | 28 entries with no text of their own |
| Book IV, Title 1 | Constitution 4 is followed by 6 | No 5 |
| Book VII, Title 62 | Constitution 34 is followed by 37 | No 35 or 36 |
| Book IX, Title 1, const. 17 | The date line comes before the text | Kept in order |
| Book IV, Title 32, const. 28 | Inscription and text on one line | Split at the end of the inscription |
| Book V | "Caasars" | Apparent typo |
| Book VIII, Book XI | Stray `«`, `•` and `£` | Apparent scanning errors |
| Books X, XI | Greek words | `χεραμεῖς` and `χρὑδαμμος`, as spelled in the source |
| Throughout | Years such as "321" at the end of date lines | Added by the translator or editor, not in Roman style |

Scott's translation has been criticized for its accuracy, so it shouldn't be used as a reference for the Latin.
